# MODO v1.1 Premium

Versión revisada a partir de las primeras pruebas de uso.

## Cambios principales

- Interfaz nocturna premium y responsive.
- Registro habitual sin texto obligatorio.
- Actividades frecuentes en dos o tres toques.
- Check-in de energía con un toque.
- Interrupciones con selección directa.
- Cierre diario basado en opciones; la nota es opcional.
- Dictado por voz para actividades personalizadas cuando el navegador lo permite.
- Frase diaria generada sin repetir combinaciones ya utilizadas en el dispositivo.
- Programas estratégicos de cuatro semanas para:
  - tiempo;
  - procrastinación;
  - energía;
  - concentración;
  - equilibrio entre trabajo y vida personal.
- Cada semana usa un método distinto, tres acciones, una métrica y una explicación personalizada.
- Recalibración del plan sin perder registros.
- Dashboard con línea base, energía, enfoque, objetivo y escenarios a 30/90 días.
- Migración automática de los datos de MODO v1 cuando se actualiza en el mismo dominio.
- Vista de demostración para revisar gráficos y análisis.
- Funcionamiento offline mediante PWA.

## Publicación en GitHub Pages

1. Descomprime el ZIP.
2. Sube a la raíz del repositorio todos los archivos que están dentro de la carpeta.
3. En GitHub: Settings → Pages → Deploy from a branch → main → /(root).
4. Espera la publicación y abre la URL de GitHub Pages.

## Actualización desde MODO v1

Si reemplazas los archivos del repositorio anterior y mantienes la misma URL, MODO intentará migrar automáticamente los datos locales guardados por la versión anterior.

En iPhone, después de publicar, cierra por completo la app instalada y vuelve a abrirla. Si continúa apareciendo la versión antigua por la caché, elimina el icono de la pantalla de inicio, abre la URL en Safari y vuelve a usar “Agregar a pantalla de inicio”.

## Alcance de esta versión

Los datos se guardan localmente en el dispositivo. No incluye todavía cuentas, nube, pagos, conexión con Google Sheets ni inteligencia artificial remota. La personalización actual se realiza con un motor de reglas basado en objetivo, fricción principal y datos registrados.
